# analyze-short-video（短视频爆款文案深度分析 + 蒸馏创作）

## 这是什么

这是一个「文案拆解 + 创作」双模式的 agent 技能（skill），跑在你的 AI 智能体里。给它一条爆款短视频/图文，它会按 19 维母框架分层拆解、提炼出**可复刻公式**与**金句**并归档进本地案例库；需要写新文案时，它会加载你的个人偏好，按公式库产出可执行文案初稿，还能把同一爆款思路**跨时长迁移**（5 分钟改 60 秒、60 秒扩到 3–5 分钟等）。

## 有什么作用

- 🧠 **深度拆解**：不只看表面套路，按 4 层 19 维母框架拆定位、内容、协同、算法，落到「为什么爆 + 怎么复刻」。
- 📐 **时长分层**：15s–3min / 3–10min / 10min+ 三档各有侧重标尺，不拿短视频完播标尺批评长视频。
- 🔁 **跨时长迁移**：压缩版（长→短）、标准版（短→中）、展开版（中→长），同一思路换时长有现成取舍速查。
- 💬 **金句库**：分析时按场景捞金句归档，创作时按场景检索复用，避免硬凑。
- 🧑🎨 **越用越懂你**：初稿 → 你微调 → 结构化 diff → 偏好沉淀进 `persona.md`，下次自动套用（含红线规避）。
- 🗂️ **案例库自我强化**：分析完的优秀爆款按 schema 归档，新公式回填公式库、新金句追加金句库。
- ⏭️ **省 token 批量蒸馏**：子代理编排 + 未蒸馏清单扫描，量大时优先省 token 铁律。

## 能帮助谁

短视频编导、自媒体运营、口播文案写手、知识博主与 AI 视频创作者——凡是需要「持续产出有爆款逻辑的文案」又不想凭空憋稿的人。它也适合文案团队做竞品拆解归档：把爆款逐条拆成可复刻公式，沉淀成团队自己的手法库。

## 解决什么问题

| 痛点 | 本技能的机制 |
|---|---|
| 🔍 看到爆款只知道"好"，说不出好在哪 | 4 层 19 维母框架逐维拆解，归因落到可复刻公式 |
| 📏 不同时长文案标准混乱 | 三档时长侧重表 + 跨时长迁移速查，先定时长档位再评价 |
| ✍️ 要写新文案时憋不出来 | 公式库 + 金句库 + 个人偏好三源驱动，出可执行初稿 |
| 📝 抄爆款怕洗稿/抄袭 | 创作守则：换表达不抄原句，只迁移结构思路 |
| 🔄 文案风格不稳定 | 个性化学习闭环：微调喂回 → 差异对比 → 偏好沉淀 |
| 📚 拆过的案例记不住 | 本地案例库归档 + 进度清单，已蒸馏的自动跳过 |

## 证据（真实运行数据）

- 案例库现有 **78 条**爆款拆解卡（分档：3–10min 中视频 48 条 / 10min+ 长视频 20 条 / 15s–3min 短视频 10 条），以抖音为主（76 条）。
- 统计由包内 `scripts/generate_intro.py` 直接读取 `references/cases/` 生成，口径可复核（打开 `intro_v1.html` 见完整图表）。
- 深度分析路径含**机制层**逐段情绪曲线、爆点秒位、结尾手法、Why+复用，不止描述现象。
- 说明：本包为 v1 首发，以上为打包时刻的真实数据快照；更多实战运行数据将随案例库扩充持续更新。

## 功能核心点

1. **19 维母框架**——4 层组织（定位与商业 / 内容与表达 / 协同与商业 / 算法与提炼创作），拆解与创作共用同一套坐标系。
2. **时长分层侧重**——15s–3min 重钩子与完播、3–10min 重结构与留人、10min+ 重价值密度与可信度，各有侧重表。
3. **可复刻公式库**——钩子公式、结构公式、留人设计法、价值公式、记忆点设计法、长视频可信度话术，分析完主动回填。
4. **跨时长迁移三件套**——压缩版 / 标准版 / 展开版 + 时长切换取舍速查表，改时长不丢爆点逻辑。
5. **个性化修改闭环**——`diff_draft.py` 结构化对比初稿与微调稿，按句式节奏/口吻人设/结构顺序等 10 维提炼偏好。
6. **批量蒸馏编排**——`scan_unprocessed.py` 未蒸馏清单 + 子代理分工（拆解/归因/入库），量越大越省 token。
7. **案例库 schema 化**——`references/cases/<时长档>/` 逐档归档，`references/mechanisms.md` 沉淀机制层手法，`gold_quotes.md` 积累场景金句。

> ⚠️ 说明：本技能内置 DIKO 授权验证（首跑一次性注册/登入）与首次赞助声明（可回复「跳过」），属包内默认机制，不列入上述卖点。

## 注意事项

- **首次使用**：先在 agent 里说触发语完成 DIKO 授权（一次注册、之后每日自动校验），再开始拆解/创作。
- **数据落盘**：案例库、公式库、金句库、偏好库都在技能文件夹 `references/` 下；重要沉淀建议随技能目录一起备份。
- **依赖能力**：仅依赖 DIKO 账号做授权；其余全部本地执行，无需额外 API key。
- **诚实边界**：公式与金句提供的是「爆款逻辑」而非「保爆保证」；题材、平台、时效都会影响实际表现，最终发布仍需人工判断。
- **隐私边界**：偏好库、案例素材、蒸馏进度全部只存你本机，不上传任何服务器。
