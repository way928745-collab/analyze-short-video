# 机制库（爆款文案的"为什么"与"怎么复刻"）

蒸馏不只要"写出它用了什么"，更要拆出**每种手法的机制（为什么有效）+ 复刻公式（下次怎么造）**。本库沉淀这些可迁移机制，供创作时按场景调用。与金句库互补：金句库给你"句子"，机制库给你"怎么搭"。

---

## 1. 情绪值定义表（-5 ~ +5，逐段量化用）

| 值 | 情绪状态 | 常见信号 |
|---|---|---|
| +5 | 极致正面 | 狂喜、热血沸腾、热泪盈眶、极致震撼 |
| +4 | 强正面 | 激动、惊喜、钦佩、嗨爆 |
| +3 | 明显正面 | 满足、兴奋、共鸣、感动、自信/爽 |
| +2 | 正向 | 愉快、被治愈、认可、会心一笑 |
| +1 | 轻微正 | 兴趣被勾起、认同、温馨 |
| 0 | 中性 | 平静叙述、科普、铺垫 |
| -1 | 轻微负 | 疑惑、轻微不适、小失落 |
| -2 | 轻度负 | 担忧、委屈、轻微反感 |
| -3 | 明显负 | 焦虑、愤怒、被冒犯、紧张 |
| -4 | 强负面 | 恐惧、暴怒、绝望感、强烈反感 |
| -5 | 极致负面 | 痛哭、愤怒到极点、深度恐惧/绝望 |

> 要点：**情绪的"落差"是爽感来源**。先靠负面/紧张建立张力，再导向正面释放；纯平铺(0→0)最无聊，纯堆正面(无落差)不深刻。

| 题材 | 典型曲线(-5~+5) | 为什么这样用 | 怎么复刻 |
|---|---|---|---|
| 情感共鸣(短) | 0→+1→+2→+3→+4 | 单次爬升、结尾到顶，让"治愈感"一步到位 | 开篇给反常识/共鸣钩子→具象画像→一句金句收顶 |
| 干货教学(中) | +1→0→+1→+2→+3→+3 | 阶梯上升、少量回落，靠"获得感"一层层给 | 每步一个小结论，步间设"下一件更重要"拉一把 |
| 深度解析(长) | +1→+2→+3→+4→+3→+4 | 多轮起伏，用震撼-回落-升华避免全程高亢腻 | 每1-2min一个新点，章间"那…呢"设问制造再起 |
| 种草带货 | -2→0→+3→+2→+3 | 先痛点焦虑立需求，再给解决感，再打消顾虑 | 痛点→产品→价值→消除顾虑→行动号召 |
| 故事/人物 | 0→+1→-2→+2→+3→+4 | 先带入再制造揪心，转折释放，感动升华 | 背景→冲突→转折→感动→升华 |

## 4. 结尾手法清单（手法 / 为什么 / 复刻 / 适用时长）

| 手法 | 为什么用 | 怎么复刻 | 适用时长 |
|---|---|---|---|
| **共鸣金句收尾** | 留一个"带得走"的记忆点，触发赞/转/藏 | 全篇铺垫后，用"不是…而是/这才是/最好的状态是…"收束到最高点 | 全档 |
| **互动提问** | 拉评论(二次分发+算法加权) | 别问 yes/no；问"你属于哪种/你怎么做/你认不认同"，且紧扣正文 | 短/中 |
| **反转** | 制造信息差爽感，促收藏(怕忘) | 埋"你以为A其实B"，结尾揭晓 | 干货/解密 |
| **价值升华** | 拔高立意，触发转发+关注("格局大") | 结尾"说到底/本质上/这背后是…"加一句人生/家国/时代金句 | 长 |
| **行动指令** | 把情绪变成动作(涨粉/收藏) | **先给足价值**，再自然"先收藏照着做/动手去试" | 教学/干货 |
| **悬念引下期** | 追更/关注 | "那你可能会问…我们下期说" | 中长系列 |
| **转化引流** | 变现 | **价值先、商业后**，后置植入，别开篇硬广 | 种草 |

## 5. 节奏与爆点设计法（爆点在哪埋 / 怎么设计 / 新文案怎么设）

**爆点类型**：数据冲击(557万/1/30)、反常识(纯强化学习)、金句、段子吐槽、悬念设问、身份共鸣。

**爆点间隔基准**（按时长分档）：
| 时长 | 爆点/信息点间隔 | 说明 |
|---|---|---|
| 15s-3min | 每 5–8s 一个 | 前半段更密，别怕快 |
| 3-10min | 每 20–40s 一个 | 段与段之间必有 |
| >10min | 每 60–120s 一个 | 每1-2min必须出新信息 |

**爆点铺设手法**：
1. 爆点前 1–3s 给**预爆提示**："但/其实/重点来了/这个很重要"。
2. 爆点揭开后留 2–3s 停顿或**高光字幕**，让观众消化。
3. 最强的两个爆点放**开头(钩子)**和**结尾(收束回响)**，中间均匀铺。
4. 每章用**设问转场**("那…呢/这也是关键")，把下一章变成"答案"。

**信息密度**：口播基准 200–220 字/分钟；干货可密到 250+(要配画面/停顿)；情感类 160–190 字/分钟。测算：字数 ÷ 时长，超出基准就需增画面/减密度。

## 6. 结构元素 why + 取用表

| 元素 | 为什么必须做 | 怎么取用 |
|---|---|---|
| **钩子** | 前3秒决定去留 | 按公式(痛点/反常识/结果前置/身份/数字/悬念)选一，首屏直接给，别铺垫 |
| **开篇(中长)** | 前15-60s定留存 | 四定(主题/收益/边界/节奏)+埋一个悬念/预告反转 |
| **结构** | 给认知顺滑度，不跳段 | 按题材选框架；3min+用"章节+章间设问"转场 |
| **归因** | 把"为什么爆"翻译成"下次怎么做" | 每次蒸馏产出可复刻公式，发现新手法回填公式库 |

## 使用原则
- 分析时**逐档用对应基准**（别拿短视频的爆点密度骂长视频）。
- 每个机制都要落到"为什么"+"复刻动作"，只描述不算完。
- 发现**新机制/新爆点模型**，回填本库；创作时先查本库挑模型。
- 本库与 `gold_quotes.md`(句子)、`cases/`(拆解)、`SKILL.md 公式库`(结构) 配套使用。

## 7. 新增机制（短视频档·第1波 沉淀）
- **演示型举证结构**：新品/工具类用连续高光demo轰炸当视觉论据(眼见为实)，替代干货篇的设问+案例说服；demo越亮、解说越精简越好。适用：产品/工具/效果展示。
- **"非效率而梦想"价值升维收尾**："绝不仅仅是A而是B"，把工具价值从功能(效率)升维到人(梦想/机会)，触发"我也能"+转发欲。适用：工具/科技科普结尾。
- **多波次惊奇型骨架**：工具实测给2座感官高峰(demo最炸的两段)+中段微落做呼吸，把"真听到的demo"本身当情绪高潮与完播钩子。
- **让"被测评对象"自己说最炸的话**：转述AI/被测对象原话当爆点，比博主自吐槽戏剧性与传播性更高；中段插"自证严谨"建信再抛最炸细节(升-降-更升双峰)。
- **焦虑入口+自豪出口**：用"养老/危机"做焦虑入口绑个体命运，再用"华人团队/开源/低成本"做自豪出口——破科技冷门；爆点排法"功能清单爆发→踩竞品回落→机制揭秘→反差数字→价值观收顶"。
- **零痛点惊喜种草曲线**：纯免费资源/新奇好物可不走痛点焦虑，直接 +3→+3→+4→+2→+3→+4，靠"好奇+逐层惊喜+接地气回落+宏大意象收顶"种草，用"白嫖/零门槛"替代焦虑需求。
- **宏观新闻→个人机会 杠杆收尾**："只要你X，你就能YY"，把行业级大新闻收口到"个人可参与"，让观众从旁观者变"跟我有关"。适用：大事件快讯/新产品/超预期技术。
- **零落差情绪模板(超短干货)**：干货/暗规则类刻意拉平情绪(非情绪助推)，靠"内容过于真实+嘴替人设+单点可执行规则"扛传播；每条规则用「识别信号+应对动作」三段式落地。
- **拟人化身份反差嘴替 + 伪说明书条款清单**：用非人客体(AI)替打工人"占便宜"，"①②③条款"逐条加码滚雪球，"最重要的一点来了"悬念前置引爆，反讽自嘲收顶；把"替代焦虑"转成喜剧共情，非贩卖焦虑。

## 8. 新增机制（中视频档·第2波 沉淀）
- **Q&A式知识科普情绪曲线**：焦虑开篇→认知反转+数据爽点→共情痛点牵家人→释疑+解决感+暖收尾；"先制造焦虑、再收进安心"的管家式关怀——只制造不解决会掉粉。适用：民生/政策/知识答疑。
- **锚点倍数类比**：把无感的抽象硬指标换算成「已知锚点(4090=男孩子的梦想)×整数倍」获得具象冲击。适用：参数科普/数码。
- **大小换算画面化爆点**：超大数字+生活化参照物(24万公里/绕地球六圈)=+3。适用：一切夸张数据。
- **"连环假解决"递进张力**：买到票→还得抢景区票→有票→还得订房，每层解决了下一层更大，微降再抬。适用：过程体验/攻略。
- **反向凡尔赛反差笑点**：红到爆的内容做成"官方求大家别来"，最强笑点放70%处当社交货币。适用：反差/逆袭叙事。
- **反常识成品驱动钩 + 失败率数据埋点**：先用"成品反差"做认知钩，再用"真实失败率(100张仅2-3可用)"做唯一负值+数据冲击，论证"活儿有门槛"，抛进阶解法完成"悬念→痛点→解法"。适用：工具教学。
- **震撼入口→焦虑出口 反向收束 + FOMO钩子**：科技震撼类不走自豪/热血收顶，而用"一觉睡醒X一夜归零"FOMO进、"你剩下的优势还有多少"落后焦虑收尾，把"技术强大"翻转为"与你有关、你怕落后"，靠危机感驱动收藏+关注。适用：科技资讯/认知颠覆。
- **双同构demo双峰惊奇**：第一条压+中段微落呼吸+第二条放最强爆点(后半更强)；用"我突然想试X"好奇心自转场。适用：产品/效果演示。
- **60s新闻炸弹钩子 + 350s官方demo论据**：资讯/评测长视频双段式——参数段高开密爆(5-12s一爆)+演示段降档靠"功能连珠炮"(30-60s一个高光)用"下一个还能干嘛"替代叙事悬念，结尾垫官方彩蛋不返厂说教。适用：评测/发布会。
- **"作弊哲学"反向人设包装**：把贬义词(投机/偷袭)正向包装成"通透/玩家思维/会挑赛道"，贩卖"我可以不公平但我赢了"的优越爽感(认知颠覆+爽感)。适用：观点/认知类。
- **金句连发点题(回旋镖)**：同一观点用三个递进动词反复敲——"评价你→定义你→奖励你"。适用：观点升华。
- **自我拆台式开场降防御**：开篇"没草稿/随时删/聊到哪算哪"破说教防御。适用：即兴/观点口播。
- **观点"压抑低谷"段落**：回报/顿悟之间插一段真实-2气馁低谷，制造落差再拔高，比全程正能量更可信。适用：中长观点/故事。

## 9. 新增机制（中视频档·第3波 沉淀）
- **教程+彩蛋 抗流失曲线**：配置/步骤最易流失段之后埋"免费增值彩蛋"(FLUX/知识库/薅羊毛)再冲高；"别XX(反共识)+只需N步(极简)"双重钩；"快人半步"口号式关注(把裸求关注译成稀缺/领先感)。
- **科幻成真反差钩 + 功能连珠炮转场 + 结局双收**：用"正式走进现实"拉科幻回现实做反差震撼；卖点用"当然不只/更科幻的是"逐级加码、段尾抛悬念；结尾"定义权"格局句促转发，紧跟"不是X是Y/是路线图"边界句保合规。
- **接力式论战链条结构**：上一场胜利即下一场战争开端(答案→立即新问号)，段段小结论+段段小钩子，天然契合 3-10min 分段留存。
- **顿悟体验式情绪模型**(第三种引擎)：认知快感+崇高感，反转驱动+峰值验证+哲学收顶(区别于焦虑/治愈/惊叹类)。
- **惊奇清单→暗面反转→辩证回稳 模板**：工具/科技安利先堆8分钟demo惊叹+信任，结尾用"它带来的风险/骗局"反转砸至负、一句辩证回稳、以"机会+警惕"回暖——把惊喜升维成信任议题，强转发防"只会唱赞歌"。
- **资源全家桶收藏钩**：开篇"全部+素材也给你"体量承诺替代单卖点诱收藏。
- **逐职业代入拉停留**：逐一点名AI视频者/租房者/地理老师/眼镜厂商，多角色共鸣防清单中段掉人。
- **一个概念×正反双面×多实验证据链 骨架**：信念-大脑预测一线串，安慰剂(正)→反安慰剂(反)→宗教/正念(解)→赋能(升)；极端个案开场→追溯认知史时间轴；抽象概念形象化收口(预测机器/操作系统/过期剧本)。
- **人群纵切清单式演示结构**：同一工具不按功能讲，按"谁用/哪类人"纵切(追星→家庭→专业→普通人→防骗)，每层一小demo+微高光，层间口语命令转场，换人群=换叙事。
- **零痛点惊喜种草+双负值刹车收顶**：正能量区占多数，仅插2处短负值(技术难点/社会警示)再升华翻回收顶，规避高开腻走。
- **否定警示式认知颠覆钩+平收互动收尾**：以"不要相信你看到的视频"否认现实认知入场，结尾用"一起找破绽"把观众变参与者而非"你惨了"。
- **炫富白日梦爽感当入门券**(dopamine-as-onboarding)：用"花光首富的钱"虚拟暴富爽剧当3秒钩，炫富清单每2-5s一个购买项+"还有呢/再来点/有没有更烧钱"链式驱动做高潮，再用"钱花不完→投资性消费→普通人做个人版"认知反转落地，最后"你也能造"价值升华软化广告。

## 10. 新增机制（中视频档·第4波 沉淀）
- **"先憋屈后扬眉"史实叙事**：底部起势(在场+设问吊好奇)→连环设问升降→史实段凿唯一深谷-3(屈辱/被卡脖子)→阶梯爬升→数据+4×连发收顶。适用：大国重器/产业逆袭/家国题材。
- **亲临现场+拟人化生活化双类比**：冷工程用"我在现场边走边讲+设问沉底"翻译，每个机关翻成器官/生活物件(主轴承=心脏/刀头=牙齿/驾驶舱=太空舱)，放低理解门槛。
- **由场面入、由道理出 + 落地刹车**：具象海量堆叠(70品类/上千款)反衬单一本质；宏大铺垫后用一句接地气判断句("信能不能卖")踩刹车立可靠性，防空谈。
- **高抽象处必配大众类比**：千问=安卓/底座，把抽象大模型讲成人人秒懂(记忆点+低理解成本)。
- **"答应我不是XX工人"第二人称身份解放收尾**：先给足干货，再用"答应我，不再做XX工人+你是最棒的"把学技能升维成"你被解放了"(共鸣转发)；结尾别回说教。
- **提示词心法反转**：把"人给指令"翻转成"AI反问、人补上下文"——AI协助类教学即时解决"还得我输入半天"痛点。
