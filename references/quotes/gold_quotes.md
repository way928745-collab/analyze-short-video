# 金句库（可复用资产）

蒸馏每条爆款时，除了提炼"归因公式"，还要把里面的**金句/高光句**抽出来，并标注**它能在什么场景用**。创作新文案时，按"场景标签"从本库捞金句，结合新主题改写复用——这就是"蒸馏喂给创作"的直接桥梁。

## 场景标签速查（创作时先按这个找）
- **反消费主义 / 内卷治愈 / 重新定义成功** → 「人生就是这样…」
- **行动号召 / 破除"先学会再用"** → 「先上场」
- **科技格局 / 民族自信 / 家国情怀** → 「国运」
- **客观辩证 / 可信度边界（长视频）** → 「站在巨人肩膀上」
- **科普通俗化 / 把复杂讲透** → 「阿哈时刻」

---

## 反消费主义 / 内卷治愈 / 重新定义成功
- **金句**：「当你物质欲望降低了之后，你会发现人生的幸福感是直线飙升的。」
  - **可使用场景**：反内卷、反消费主义、重新定义"成功/幸福"，让人释然、向往、被治愈。
  - **用途**：中后段记忆点 / 结尾升华 / 封面字。
  - **适用时长**：短视频、全档。
  - **用法提示**：先用"不买哪些东西"铺具象画像，再抛这句做转折点睛；配舒缓 BGM。
  - **出处**：`15s-3min/2026-08-26_人生顶级状态.md`
- **金句**：「人生的顶级状态，就是赚个一两百万，然后不买车、不买房、不买奢侈品。」
  - **可使用场景**：反主流消费观的话题开局，制造"还有这种活法"的好奇。
  - **用途**：开头钩子 / 封面字。
  - **适用时长**：短视频。
  - **用法提示**：开头 3 秒直接给，越具体越有冲击（配上数量词）。
  - **出处**：`15s-3min/2026-08-26_人生顶级状态.md`

## 行动号召 / 破除"先学会再用"
- **金句**：「先上场，一边学一边用。真正会打球的人，不是看了十年教学视频，而是先上了球场。」
  - **可使用场景**：教方法、劝人行动、破除"我要先准备好/先学会再动手"的拖延与完美主义。
  - **用途**：结尾升华 / 记忆点 / 评论互动（"你现在是哪种？"）。
  - **适用时长**：短视频（精简成"先上场"）、中视频、全档。
  - **用法提示**：用一个生活化类比（打球/游泳）把抽象理念一次讲透，比讲道理更容易被记住和转发。
  - **出处**：`3-10min-mid/2026-07-10_零基础搭AI知识库四步闭环.md`

## 科技格局 / 民族自信 / 家国情怀
- **金句**：「中国也可以的信心和希望，这才是我们要守护的国运。」
  - **可使用场景**：中国科技突破、国产替代、AI/芯片/航天等"触动民族情绪"的话题，结尾拔高。
  - **用途**：结尾升华 / 封面字。
  - **适用时长**：长视频（也可切 60s 高光短视频）。
  - **用法提示**：放在整个论证（数据+对比+困境）已经铺满之后，情绪被推到最后再给，突然拔高；避免硬上价值。
  - **出处**：`10min-plus/2025-01-31_Deepseek为什么这么火.md`
- **金句**：「一个让美国总统和科技巨头都暴跳如雷的中国小公司。」
  - **可使用场景**：讲中国科技公司/事件的开头，用"反差+身份重量"抓人。
  - **用途**：开头钩子。
  - **适用时长**：全档。
  - **用法提示**：开头 3-5 秒；"暴跳如雷/让巨头睡不着"这类强动词比"厉害"有画面。
  - **出处**：`10min-plus/2025-01-31_Deepseek为什么这么火.md`
- **金句**：「AI 是先进生产力，甚至未来是比人类更聪明的生产资源。掌握 AI，就相当于掌握了权力。」
  - **可使用场景**：AI 宏观格局、为什么要重视 AI、科技竞争本质。
  - **用途**：中段观点记忆点 / 标题 / 封面。
  - **适用时长**：中视频、长视频。
  - **用法提示**：作为"格局层"的观点锚点，配数据/事件佐证；可用于观点类视频的中段高压点。
  - **出处**：`10min-plus/2025-01-31_Deepseek为什么这么火.md`

## 客观辩证 / 可信度边界（长视频）
- **金句**：「严格来说，DeepSeek 也是站在巨人的肩膀上。暂时的赢，不是胜利。」
  - **可使用场景**：给火爆/结论性事件降温、保持客观、避免吹捧过头引发抬杠。
  - **用途**：中后段辩证 / 标注适用边界。
  - **适用时长**：长视频。
  - **用法提示**：紧跟"它很牛"之后，"也不是/但是/严格来说"留出边界，权威感和合规双收。
  - **出处**：`10min-plus/2025-01-31_Deepseek为什么这么火.md`

## 科普通俗化 / 把复杂讲透
- **金句**：「那中间的关键推理步骤，叫『阿哈时刻』——就是那种没有指导、自发产生的顿悟。」
  - **可使用场景**：把硬核技术/原理讲成普通人能懂的故事，制造"恍然大悟"。
  - **用途**：中段记忆点 / 讲解转折。
  - **适用时长**：中视频、长视频。
  - **用法提示**：给抽象概念起一个"人话名字"（阿哈时刻/先上场/盗梦空间种子），配合"原来这才是关键"。
  - **出处**：`10min-plus/2025-01-31_Deepseek为什么这么火.md`
