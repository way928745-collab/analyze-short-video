# 金句库说明（schema + 使用方法）

## 是什么
`gold_quotes.md` 是从已蒸馏爆款里抽出的**可复用金句**，每条都标注了**可使用场景**。它和案例库(`cases/`)互补：
- `cases/` 存"整条文案怎么拆、为什么爆"
- `quotes/` 存"能直接拎出来用的句子 + 在哪用"

## 金句入库 schema（每条 6 要素）
```yaml
- **金句**：「一句话」
  - **可使用场景**：什么主题/情绪/环节用它（核心）
  - **用途**：开头钩子 / 中段记忆点 / 结尾升华 / 封面字 / 评论互动
  - **适用时长**：短视频 / 中视频 / 长视频 / 全档
  - **用法提示**：怎么用、配什么（BGM/铺垫/位置）
  - **出处**：来自哪篇案例（`<tier>/<案例名>.md`）
```

## 入库时机
每次蒸馏一条爆款（第 2 部分"归因提炼"时），**顺手抽 1-3 条金句**按上述 schema 追加进来；发现新场景标签就在文首"场景标签速查"加一行。这是"蒸馏喂给创作"的直接资产。

## 创作时怎么查用（第 5 部分工作流用）
1. 先定创作主题/情绪 → 到"场景标签速查"定位相关标签。
2. 用 `skill_view(file_path='references/quotes/gold_quotes.md')` 或 grep 该标签段，捞适配金句。
3. **结合新主题改写**（金句是"句式/情绪/结构"参考，不是照抄）；标明"复用自 xx 案例金句"。

## 去重与强化
- 同一句不重复入库；同一场景多句时标注优先级（哪句最狠/最通用）。
- 发现新的好用金句随时补；已蒸馏的案例也应在入库时补充其金句到本库。
