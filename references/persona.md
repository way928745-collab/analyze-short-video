# 个性化创作偏好库（用户微调学习）

> 本库记录**你的个人创作口味**。循环：我出初稿 → 你微调喂回 → 我对比差异 → 沉淀成偏好条目 → **下次生成自动套用**，越用越贴你。
> 偏好是"你喜欢/反感的具体做法"，不是"要口语化"这种空话。本库持续积累中，从真实微调填充。**终稿润色/生成前必读本库全文，"喜欢"项为硬检、"反感/红线"项为硬禁。**

## 偏好条目格式（每条 = 一个你反复改的做法）
```yaml
- **维度**：句式 / 口吻人设 / 结构顺序 / 长度密度 / 金句 / 爆点风格 / 标点语气词 / 结尾 / 题材偏好 / 禁忌红线
  - **你喜欢**：具体做法（带例子）
  - **你避免/反感**：具体做法（带例子）
  - **来源**：初稿「…」 → 你改成「…」（一次真实微调）
  - **应用规则**：生成时怎么做（如"开场必用一句反问"）
```

## 各维度检查清单（生成/微调分析时逐项对照）
- **句式与节奏**：长句 vs 短句占比；排比？反问/设问？顶针？句子长度是否随情绪变化。
- **口吻/人设**：温柔/直接/犀利/幽默/导师/朋友；称呼("你/大家/家人们")；自嘲 vs 说教。
- **结构与顺序**：是否 1/2/3 清单化；章节多少；铺垫多少；结论前置还是后置。
- **长度与密度**：字数/时长；信息密度；留白停顿；是否删了赘述。
- **金句**：对仗/反转/数字/短句；金句放开头/中段/结尾；要不要可截图。
- **爆点风格**：数字冲击/段子/反常识/悬念/身份共鸣；爆点间隔。
- **标点与语气词**：，。？！、～；语气词(啊/嘛/呢/哈)数量；emoji 多少与位置。
- **结尾偏好**：互动提问/升华/行动指令/悬念引下期/转化；结尾长度。
- **题材偏好**：偏爱哪类(干货/情感/种草/科技…)；避开哪类；对"广告/硬广"的容忍度。
- **禁忌红线**：绝不用某词(绝对化/极限词)；不卖惨；不制造焦虑；不要某套路(如"求你转发")。

## 用法
- **生成前**：先读本库，把"喜欢"的偏好默认调用，把"反感/红线"主动规避。
- **收到微调后**：用 `scripts/diff_draft.py` 对比初稿与微调稿 → 逐维度提炼差异 → 追加成新条目（或合并/强化既有条目）。
- 同一条偏好反复出现 → 标记为**强偏好**，生成时优先执行。
