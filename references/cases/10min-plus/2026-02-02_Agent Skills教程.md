# 手把手彻底学会 Agent Skills！【小白教程】

## 一、核心内容(2-3句概括)
用"秋之餐厅品牌创意生成器"一个**逐步升级的实操案例**，从零教观众创建自己的 Agent Skill：先建最简 skill.md（原信息+指令），再升级到按需加载的 references/scripts/assets 三层结构，最后落到"渐进式披露"机制。收尾给出免手写的选择题式"秋知 Skill 创建器"、现成 skill 仓库、几款普通人必备 skill，并用打工人周报/老师备课/文章配图/审合同四个场景教你怎么只打磨最高频的一件事。

## 二、归因提炼(可复刻公式)
- **逐步升级案例法**：同一个"做海报"需求，从最简单 skill.md → references → scripts/assets → 完整形态，每步只推进一步，观众亲手跟着"长"出技能，全程不抽象。
- **降维类比**："skill 像厨师技能=流程+配方+工具+独家材料"；"一个英雄只 4 个技能 QWER 杀遍全场"，把高门槛工程概念拉回生活。
- **二次质疑制造认知张力**：观众刚想"这不就是写提示词吗"，博主先承认"本质上还真是"，再反转"但工程上优势很多"，用自问自答把痛点→解法流畅带出（157s、381s 两次）。
- **高光演示留证据**：让它"做一张周六饮料免费实体海报"，然后展示"尺寸配色 logo 完全符合品牌规范"的成品图（775s），用结果证能力，替代纯口播。
- **价值闭环**：概念→动手→机制→工具降门槛→场景代入，层层递进，收尾把"复杂技能"降维成"人人都可重复劳动外包"。

## 五、结尾手法(为什么+复刻)
**共鸣场景+价值升华+行动指令**三连。先给打工人周报/老师备课/配图/审合同四个高频场景（强共鸣、用户代入自己",收藏欲最强=涨收藏率）；再升华"把掌握的小技能交给 AI 替你重复劳动"（=人设价值）；最后"资料链接在评论区，动手试试+点赞收藏关注"（=评论区/转发/涨粉）。
**为什么**：长视频第一指标=收藏率/粉丝转化，四个具体场景是"我正好用得上"的收藏钩子；升华句造人设（AI 带路人）；评论区放资料做引流沉淀。
**怎么复刻**：结尾句式=「其实你(高频场景)×3 + 你只要把它交给AI + 资料在评论区 + 点赞收藏关注」；场景要具体到身份，越具体越能"对号入座"。

- 开篇：0-60s 完成"定主题(教你做skill)+定收益(逐步升级案例+定制自己的)+定边界(零基础)+定节奏(给资料/给神器)"→为什么=长视频开篇必圈住"我从哪来、能学到啥、难不难"；取用=0-60s 四定模板。
