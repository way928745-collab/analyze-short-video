# 中老年人豆包AI使用指南（7分43秒 / ≈1738字 / emotion=NEUTRAL 实为温馨治愈底）

## 一、文案核心内容
别回家只带保健品。"今年回家过年最该做的一件事，就是教会爸妈用AI"。作者准备好一套「中老年AI使用指南」，把手机"转交"给长辈，用直播一样的态度一句句教叔叔阿姨用**豆包AI**（免费、上春晚、像手机里的好朋友）。功能逐个演示：**打电话/打视频（能看手机屏幕）、方言识别、免费打电话、健康问答（高血压喝酒）、远程指导修遥控器/电器的视频示范、屏幕字体放大一步步实操、导航指路、AI合唱、P照片、提醒吃药、陪聊心事**。演示完把手机"转交"回年轻子女，结尾升华——"AI可以让父母生活更好，但替代不了你在他们身边；AI很重要，你的爱更重要，所以多打电话、常回家看看"。**内核：把"教爸妈用AI"变成"给爸妈留一个永远秒回的依靠"。**

## 二、母框架拆解（3-10min 标尺）
- **开篇(0-15s，对孩子)**：钩子=身份标签+结果前置。"今年回家过年你最该做的一件事儿就是教会爸妈和长辈用AI"，立刻点价值——"长辈们缺的早不是吃的喝的保健品，是一套跟得上时代的生存技能"。**讲什么(教爸妈用AI)+有何收益(他们少踩坑、跟上时代)+体量(中老年AI使用指南)** 三锁定，0-15s建立完整预期。
- **结构**：**双层受众 + 视角切换式演示结构**。整条视频借"转交手机/收回手机"这个物理动作做**转场道具**：前半段对长辈（）说话，逐个功能上"场景式小demo"；中后段"把手机转交回孩子"切回子女视角，从演示转入情感升华。功能部分是并列清单，用"不光…还能…""而且啊…"的**口语连珠炮**串起来。
- **分段留人**：3-10min关键。功能**每20-40s一个新爆点**（打电话→打视频→看屏幕→字体放大→导航→合唱→P图→提醒吃药→陪聊），每段一个独立小结论+小兴奋点，段间用"不光…还能…""而且啊…""那再比如…"口语转场黏住，防中段掉人。
- **语言/人设**：**一人分饰两角/两种语态**。对长辈用最温柔耐心的"子侄式"口吻（"叔叔阿姨过年好""您别怕""别着急慢慢来""我一直在这儿"），对子女用"同龄人"口吻（"朋友们""咱们最起码能做的是"）。全程零说教感，用"您/咱"消解距离，极适配中老年受众。
- **价值**：主=实用（豆包各功能可直接教会长辈）+ 副=**情绪**（"AI替代不了你，你的爱更重要"，把工具价值升维到亲情）。**"实用清单"做壳、"亲情感动"做魂**——这是它比纯教学更爆的原因。
- **记忆点**：**「AI很重要，你的爱更重要」**（结尾金句，全场最强）；**「教会爸妈AI=永远秒回的耐心依靠」**；**「奶奶，我在呢…我一直在这儿」**（AI当陪伴，泪点场景）；封面数字tag"人类对豆包开发不足1%"。
- **结尾**：**共鸣金句+价值升华+行动指令**三连。先升华"AI替代不了你在身边"，金句"你的爱更重要"，再落到"所以多打电话、常回家看看"，最后挂"转发给父母+明年见"。情绪收在最高点，指令落在转发/关注。
- **论据**：全片用**"真对话场景"做论据**——高血压会不会醉、遥控器怎么按、字体怎么放大、植物枯萎，都是"长辈真实会遇到"的场景，比讲参数可信一百倍，是"知识输出型"的教学**实证化**样板。
- **商业/合规**：全程无广告味，豆包是"好用产品"而非"带货"；免费大字标注降低戒备；健康问答给出"建议不喝"的边界，无夸大。**春晚/免费**是信任背书。

## 三、爆款归因提炼（可复刻公式）
1. **钩子公式 = 身份标签 + 结果前置 + 亲情节拍**：过年这场合天然带"孝顺/团圆"情绪，用"回家最该做的一件事"把观众从"刷视频"拽进"我该帮爸妈做点什么"。
2. **结构公式 = 双受众视角切换 + 转场道具**：用"转交手机/收回手机"做物理转场，一条视频同时打动"子女(转发/采集者)"和"长辈(使用者)"。
3. **留人手法 = 功能连珠炮 + 一次一个动作demo**：每20-40s一个新功能，每个功能用"一句话生活场景"演示，段间"不光…还能…"黏住，中段不冷场。
4. **价值公式 = 实用做壳 + 情感做魂**：8分钟功能教学不让人觉得"广告"，因为结尾把工具升维成"你不在时的陪伴"，触动"我的爸妈也需要"。
5. **记忆点设计 = 一句话定义 + 一句泪点金句**：把"AI"翻译成"永远秒回的依靠"，把"你的爱更重要"做成可截图转发的话。
6. **行动号召 = 情绪最高点收口**：金句之后立刻"多打电话、常回家看看、转发给父母"，让情绪直接转成动作。
