# 案例 · AI二维码喂饭级教学（音轨实测 ~80s / 363字 / emotion=HAPPY，档位按任务定为 3-10min-mid）

> 说明：源目录归入"中视频"档（3–10min），按任务归档到本目录；但本轮音频转写实测仅 ~80.2s / 363 汉字，结尾含"关注/没"的口语未说完部分。拆解以实测为准，爆点密度相应按"讲解密集"处理。

## 一、文案核心内容
教学"用 Stable Diffusion 做一个**不像二维码的二维码**（隐藏定位点）"：①装 2 个插件（ControlNet 类 + Adetailer）②用草料把二维码解码出内容、复制进插件 ③第一步用一个模型、调容错率/角度/样式/尺寸/噪点，控制权重从大到小（数值越大成功率越高但定位点越明显）④**实测 1.5 的控制权重成功率与融合度最好** ⑤单模型成功率极低（100 张仅 2–3 张可用）⑥套第二个模型：控制权重别太大、拉到 0.3，进出时机放中段/后段、保持 30%–40% 控制时间 ⑦最后开 Adetailer 面部修复生成即可。开头用"卖300/能值多少"坐实变现价值，末尾"模型参数我会放在…关注"留关注钩子。

## 二、母框架拆解（3-10min 标尺）
- **开篇/钩子(0.2–6.7s)**：三重叠加钩子——**结果前置+金钱数字**（"做个二维码就能卖300""能值多少"）→**反常识反差**（"不像二维码的二维码"）→**人设承诺**（"今天大法师就教你"）。把"看下去能得到什么（值钱的成品）"前 3 秒直接给，且用一个反常识概念勾住好奇心，不铺垫。
- **结构**：干货教学框架「激发兴趣/价值锚定→工具准备→第一版跑通→失败率埋点→设问转场→进阶解法→收尾CTA」，本质是**"先给一个能跑的初版→再告诉你它其实会翻车→再教你进阶参数"**的问题-解决型骨架。
- **语言/人设**：自称"**大法师**"（俏皮技术人设）+ 网感口语（"这个效果嗯""直接抄我作业"）+ 命令式喂饭语气（"不会设置的同学直接抄我作业"）。说教感被自嘲与"保姆式喂饭"消解，拉近与技术小白的距离。
- **核心价值**：主=**实用**（可亲手做一个能卖 300 的成品，且给具体参数 0.3/1.5/30–40% 照抄即可）+ 副=**认知/情绪**（"原来二维码可以做得不像二维码"的反常识惊喜 + "这个东西能赚钱"的变现想象）。
- **记忆点**：**"不像二维码的二维码"**（反常识概念）+ **"卖300"**（金钱数字）+ **"抄我作业"**（喂饭级低门槛）+ **"100张只有2-3张可用"**（真实失败率）。
- **分段留人**：中段靠"**但是**……成功率会非常低"转折 + "**怎么提高成功率呢？**"设问转场 + "不会设置的同学**直接抄我作业**"低门槛钩子，三连撑住中间不掉人。
- **结尾(77.6s起)**：**"模型和参数设置我会放在……关注。没。"**——用"放"暗示资料在别处 + 一句俏皮"没"字断句收尾，把关注引导藏在"没说完"的悬念里。
- **商业/合规**：以"能卖300"坐实**变现想象**（副业/外快暗示），但无硬广、无割韭菜话术；合规注意：①"扫码/卖码"类创意设计教学本身低风险，但避免暗示"无限赚钱"强化副业焦虑；②教生成可能被商用的二维码时，不引导用于伪造/诈骗场景即可。

## 三、爆款归因提炼（可复刻公式）
1. **钩子公式 = 成品金钱数字 + 名词反差 + 一句悬问**：把"卖300/值多少"放最前，再抛"不像二维码的二维码"反差概念，一个问句把它串起来。首屏即"价值+新奇"，双钩。
2. **结构公式 = 初版跑通 → 失败率埋点 → 进阶解法**：先让观众看到"能做出一个"给信心(+2)，再用"100张仅2-3张可用"泼冷水埋痛点(-1)，最后"第二个模型+0.3+30-40%控制时间"给进阶收获(+3)。痛点阶梯是本题爽感主线。
3. **留人手法 = 设问转场 + 低门槛承诺**："怎么提高成功率呢？"是标准章间设问；"不会设置的同学直接抄我作业"把"要学会"转成"你只管抄"，拆掉行动门槛。
4. **价值策略 = 喂饭级 + 参数兜底**：给"0.3 / 1.5 / 30–40% 控制时间"这种**可直接照抄的数字**，比讲原理更能催动"立刻上手"，也天然呼唤收藏。
5. **记忆点/转发 = 反常识概念 + 真实失败率**："不像二维码的二维码"自带转发性；"100张2-3可用"是真实数据冲击，给"这活儿有技巧"背书。

## 五、跨时长迁移建议
- **压成 <60s**：只留"卖300钩子 + 不像二维码反差 + 抄我作业低门槛 + 一个能成的参数(0.3/1.5) + 结尾命令"，砍掉拆装插件与 Adetailer 的细枝末节；失败率埋点保留一句即可。
- **展开成 >10min**：每步配**真实屏幕录制+结果扫一扫演示**（视觉论据，见机制库"演示型举证结构"）；补"为什么控制权重高定位点就明显"的 ControlNet 原理层；中段加 2–3 个失败/丑案例对比；结尾引导"评论区发你做的版本"拉互动。

## 六、机制层深度分析

### 1. 逐段情绪曲线（-5~+5，段级，不跳段）
`0.2s 卖300/值多少(钩子) → +2` ｜ `6.7s 大法师教你做不像二维码 → +1` ｜ `10.3s 装插件/草料解码/调参(讲解) → 0` ｜ `31.2s 抄我作业/第一版跑通 → +1` ｜ `46s 1.5成功率融合度最好 → +2` ｜ `49s 但单模型成功率低·100张2-3可用 → -1` ｜ `54.9s 怎么提高成功率(设问) → +1` ｜ `56-66s 第二个模型/0.3/控制权重 → +2` ｜ `67s 30-40%控制时间 → +2` ｜ `72.8s Adetailer生成点一下 → +3` ｜ `77.6s-尾 参数我放这/关注/没 → +2`

**曲线**：`+2 → +1 → 0 → +1 → +2 → -1 → +1 → +2 → +2 → +3 → +2`
**为什么这么排**：这是教学类典型的"**小S型转折**"——开头用价值+反差拱起+2兴趣；中段是密集步骤、情绪故意落在温和(0~+2)（靠"抄我作业/怎么提高成功率"口语钩子吊着）；**唯一的 -1 极刻意放在"100张只有2-3可用"**，用一次小挫败制造张力落差，再经设问拉起，把最高 +3 留给"点一下生成就成"的**成就感收顶**。教学类绝不全程高亢，靠"给信心→泼冷水→给收获"制造跌宕。**复用**：同类工具/软件教学，就在"第一版跑通"和"进阶参数"之间，必插一个失败率/翻车数据当短暂负值，让用户跟着"着急一下再被喂饱"。

### 2. 结尾手法
**行动指令 + 悬念引下期/引详情 + 俏皮断句**（"模型和参数设置我会放在……关注。没。"）。
- **为什么这么用**：想拿的是**关注**（参数/课件放在主页或评论区，需关注才能拿到）+ **收藏**（教程型参数天然要收藏照做）。故意把"放在😏"留一半，用一句俏皮"没"字断句，制造"话没说完"的轻悬念。
- **怎么复刻**：教学结尾用"完整参数/作业/课件我会放在（评论区/主页/群里）"自然承接资料获取，落点用一个**极短俏皮字**（"没/懂/冲/稳"）收束，把干巴巴的"求关注"变成有记忆点的亮句。

### 3. 节奏与爆点（秒位全标注）
爆点：`0.2`卖300钩子(数字) ｜ `6.7`不像二维码(反差概念) ｜ `10.3`插件+草料解码(工具名) ｜ `31.2`抄我作业(低门槛人设) ｜ `46`1.5融合度最好(参数数据) ｜ `49`100张仅2-3可用(**数据冲击/痛点**) ｜ `54.9`怎么提高成功率(设问转场) ｜ `60`控制权重/成功率干货 ｜ `66`拉到0.3(参数) ｜ `67`30-40%控制时间(精度) ｜ `72.8`点生成就成(成果) ｜ `77.6`参数我放这/关注(CTA悬念)。
**间隔**：约 4–12s 一个，**非常密**（因实际内容仅 ~80s 且为讲解+演示混剪）。——注：任务按"3-10min"档归档，但本轮实测时长落在"短视频"密度区间（每 5–8s 一个爆点的偏密版），此处以实测为准。
**信息密度**：363字 / 80.2s ≈ **272字/分钟**（口播偏快，靠屏幕演示画面分担信息负荷，属正常偏密）。
**新文案怎么设**：同主题新教学——首屏"成品+钱+反差"三连钩 → 每步一"口播小爆点"(参数/神器名/笑点) → 中段必埋一个"失败率/翻车"数据冲击 → 结尾"参数放评论区+一个俏皮短字"收 CTA。

### 4. 情绪元素调用
题材=**AI工具教学/干货**。调用：**好奇(卖300/不像二维码)→惊喜/兴奋(第一版跑通)→小挫败(失败率)→期待(设问)→成就感(点生成就成)→共鸣(怕学不会) → 冲动(想照做赚300)**；核心是"获得感 + 低门槛(抄我作业) + 变现想象"。
**换题材该调什么**：做成「情感治愈」→ 换 共鸣→释然→治愈；做成「观点/认知」→ 换 惊讶→顿悟→优越感（把"不像二维码"做大成认知颠覆）；做成「种草带货」→ 换 痛点焦虑→解决感→冲动。若要从"教学"转向"纯变现引流"，则保留好奇+冲动，放大"卖300"减少技术细节。

### 5. Why + 复用（钩子/开篇/结构/归因）
- **钩子**：为什么——前 3 秒定去留，"能卖300+不像二维码"同时给"值钱的结果"与"新奇的认知"，双钩拉满；复用——首屏用「成品/金钱数字 + 名词反转 + 一句问句」三件套。
- **开篇**：为什么——前 10 秒把"主题(做二维码)+反差卖点(不像)+门槛承诺(喂饭级/抄我作业)"全部交代，定留存；复用——教学开篇必"结果画面 + 反常识卖点 + 低门槛承诺".
