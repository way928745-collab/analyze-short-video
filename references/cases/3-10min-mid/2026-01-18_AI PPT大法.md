# 案例 · 豆包 AI PPT 万能大法（音轨实测 297.08s / 1169 汉字 / emotion=NEUTRAL，档位 3-10min-mid）

> 权威源字段核对：`emotion=NEUTRAL`（整段中性偏“教程播报”基调，但内嵌大量 demo 惊叹与共鸣激励）。真实时长取 `words` 最大结束时间 = **297.08s ≈ 4.95 分钟**（`elapsed_sec` 不可信）。**标题写“三分钟”，实际 297s**——开篇用“3分钟”做低时间成本钩子，但与真实时长有落差（后文合规提示）。sp=1169 汉字 / 297s ≈ **236 字/min**（高于口播 220 基准，属快节奏演示教学，靠满屏录屏 demo 分摊信息负荷）。内容形态为**演示型画面解说**：口播抛方法 + 连续豆包界面录屏演示做视觉论据。

## 一、文案核心内容
一条**分级进阶式教学干货**：教你在**豆包**里用一套“走你公式”**四集连发**地批量做 PPT。核心是一套**万能提示词模板**（我是什么角色？正在准备做面向什么受众的什么类型 PPT？想重点展示什么？要求怎么样的风格？），并给出了**一鱼四吃的进阶玩法**：①**基础版**——套万能提示词直接选“PPT 生成”，豆包会自主拆解主题维度→搜 20+ 资料→设计逻辑风格→定字体/色彩/可读性规格→逐页设计→缺图自动生成·缺图表自动列数据；②**反问版**（第二集）——只需在公式后加一句「**为了帮我做好这个 PPT，需要我给你提供哪些信息？你来向我提问**」，让 AI 反过来问你，适合个人年终总结等网上没资料的内容；③**深度调查版**（第三集）——资料多时先跑“深度调查”，得到一份 200+ 参考引用的全面报告，下载后上传再拷公式；④**图片参考版**（第四集）——风格描述词想不出时，直接把喜欢的风格截图发给它（豆包背后是某“C”图片模型，很能生图），加上走你公式即做出“谁也找不到的私人定制模板”。末了再补**修改能力**：压缩页数/换风格/加插图/加饼图/加真人/重搜网图/手动编辑，随时回退版本，且**每页自动生成对应演讲稿**，落点“老板说明天就要的场合”。结尾把方法抽象成**一句话认知**："其实它这个 Agent 本身就会帮你做主题拆解、资料搜索、版式设计、素材生成、排版制作，**你只需要给足上下文**（可让它反问/给它参考/给它已有资料报告，或三者结合），剩下的让 Agent 自己去干——这也是今年会成为主流的一种 AI 协作方式。"收在「**答应我，不再做 PPT 工人，你是最棒的**」的情绪激励上，最后点赞收藏关注。

## 二、母框架拆解（3-10min 标尺）
- **开篇/钩子(0.1–25.5s)**：**结果前置 + 数字冲击 + 反模板 + 低门槛 + 收藏钩**五连。首句"给我3分钟，让你一天能做**20个**这样的 PPT"——用"3分钟/20个/一天"做**低时间成本+高产出**双钩；紧接着用"**不是模板，不会重复，数据详实，还有洞察，图片也是定制**"四点**否定模板化**；再补"演讲稿自动配好+**完全免费**"去门槛；最后一句"现在还没点好收藏关注吗？**小心损失一个亿**"用**夸张调侃**把人拽到收藏动作。0-15s 就把"讲什么(做PPT)+收益(20个/免费/定制)+行动(收藏)"一次给足。
- **结构**：**分级进阶教程骨架**「总钩 → 4 集逐级推进(每集先用"上一级局限"开新痛点) → 修改能力 → 方法论抽象 → 情绪收顶」。1→4 集按**"下一集解决上一集不够"**的递进排：第1集嫌"会很水"→升级细节证明不水；第2集解决"网上没资料";第3集解决"数据多一个报告不够";第4集解决"风格词想不出"。每集小钩子用口语命令转场开（"然而还有的朋友说…/这不还有第三集/小case第4集来了"）。结尾 267s 起做**认知抽象**（把具体玩法拔成"给足上下文即可"的方法论）+ 一句**前瞻判断**（"这是今年会成为主流的 AI 协作方式"）再情绪收顶。
- **语言/人设**：**网感老友/技术安利型**——大量语气词与网感梗（"no no no/Oh/Nice.ok/小case/当当当当/科技真奇妙/当当当"）、中英混用、自称"那套大法/走你公式"；用"**走你公式**"给可复用的提示词**命名造记忆点**（"走你"= 出发/起飞，自带动作感）。口语短句多、节奏快（236 字/min）。与"朋友安利"人设统一，无一味说教。
- **核心价值**：主=**实用**（一套可直接照抄的万能提示词 + 4 种递进用法 + "老板明天就要"场景）；副=**认知**（Agent 协作新范式："你给上下文、AI 干重活"）+ **情绪**（"不再做 PPT 工人"的反内卷共鸣/爽感激励）。一主两副，覆盖收藏/评论/关注三类动机。
- **记忆点**：**「走你公式」**（命名化万能提示词，最强记忆点）+ **「不再做PPT工人，你是最棒的」**（情绪金句/封面字）+ **「小心损失一个亿」**（开玩笑式收藏钩）+ **「200多个参考引用的报告」**（数据冲击）+ **「让 AI 反过来问你」**（反直觉心法）。分布：开头(走你/损失一个亿)、中段(200+报告/想让AI反问)、结尾(不再做PPT工人)。
- **分段留人**：靠**"分级递进 + 每集限界钩"**撑中段——每集开头先用一句**新痛点**把上一集的局限说出来（"网上没资料/数据很多40个不够/风格词费劲"），再用"这不还有第三集/小case第4集来了"口语命令转场把观众带到下一集，形成"下一集能补上"的期待；26–44s 用"这不肯定很水吗？→no no no 人家已经升级了"做**小反转预爆**拉住起步段。
- **结尾(267s起)**：**总结 → 认知抽象 → 前瞻判断 → 共鸣情感金句 → CTA**，见第六部分。
- **商业/合规**：无硬广，全程安利"豆包"这一产品（属**工具种草/流量扶持**性质），但**未明示商业合作**、未用极限词（"完全免费"是客观陈述、"一天20个"属演示场景）。**需注意**：①标题宣称"3分钟"、实测 297s，存在标题与时长落差，建议标题改为"几分钟"降低"高开低走"风险；②"小心损失一个亿"为夸张调侃，口语语境可接受，但成片字幕若无调侃语气易引起误解，建议配合语气；③"完全免费"若与实际产品政策不符需核实。整体合规风险低。

## 三、爆款归因提炼（可复刻公式）
1. **钩子公式 = 低时间成本数字 + 高产出数字 + 否定模板化 + 免费去门槛 + 夸张收藏句**：用"**3分钟/一天20个**"把"付出的时间少 × 得到的产出多"塞进一句，再"不是模板不会重复/数据详实/图片定制/演讲稿自动配好"否定"AI 做的很水"的顾虑，用"完全免费"扫除行动门槛，最后用"**小心损失一个亿**"的调侃逼收藏。比"教你做 PPT"更能抓提效人群。
2. **结构公式 = 分级进阶教程("上一级不够→下一级补") + 小反转预爆**：把一套方法拆成 4 级递进，**每集用"上一级的局限"当新钩子**，观众因为"我的情况它的方案覆盖不了吗？"而继续看。中段用"这不肯定很水吗→no no no"先制造质疑再满足，制造第一波小反转。适合任何"方法有多个档位/进阶"的主题。
3. **留人手法 = 口语命令转场 + "局限-解决"节拍 + demo 证明**：每集之间用口语命令"这不还有第三集/小case第4集来了"做小钩子；每集内在"局限(痛点)→走你公式→结果(demo)"的节拍里推进；豆包界面用**连续录屏**当视觉论据，口播只报"它干了啥"，把信息密度交给画面。236 字/min 也不显赶，全靠 demo 分担。
4. **价值策略 = 可命名复用套路("走你公式") + 场景落地("老板明天就要") + 反内卷共鸣**：把提示词**命名化**成"走你公式"（可传播、可复刻、有记忆点）；落到"老板说明天就要"的高压场景引发打工人共鸣；结尾"**不再做PPT工人**"把人从"学技能"升维成"解放自己"。
5. **记忆点/转发 = 一句身份解放金句 + 认知前瞻**：**"答应我，不再做 PPT 工人，你是最棒的"**既是情感收顶又是可截图传播的封面金句；"让 AI 反过来问你"是全片最反直觉的心法爆点；"这是今年会成为主流的 AI 协作方式"给观众"我知道了顶层趋势"的优越感，触发转发/收藏（怕忘+要跟上）。

## 五、跨时长迁移建议
- **压成 <60s 短视频**：只留「3分钟/20个PPT(数字钩)→不是模板/免费(去顾虑)→走你公式(万能提示词模板一句)→让 AI 反问你(最反直觉心法)→不再做PPT工人(金句收顶)+收藏关注」。砍掉 1→4 集的分级、修改功能、200+ 报告细节；钩子 3 秒内给到，结论前置，节奏拉满。**保留"走你公式"命名 + "不再做PPT工人"金句**两个记忆点。
- **展开成 >10min 长视频**：升级为**章节体系**——每集一章（4 章），章内补原理层（Agent 怎么自主拆解/搜索/排版、背后图片模型机制、上下文工程是什么）、每章加 2–3 个真实案例（真实年终总结/调研报告/品牌提案）、补适用边界（哪些内容 AI 做不好、数据可靠性怎么核、敏感信息风险）。结尾做全局复盘（人给上下文、AI 干重活的协作范式）+ 下期/私域铺垫；标出可切短视频的高光段（开头数字钩 / 让AI反问 / 不再做PPT工人金句）。
- **换强情绪向**：把"教程"改成"**打工人觉醒宣言**"——开篇直接"你还在熬夜抠 PPT 吗？"情绪直给，结尾用"不再做PPT工人"做主情绪，弱化步骤、强化"解放"。更适合小红书/B站发酵。

**为什么这么排**：这是「**高位平台 + 周期性小回落到 -1 + 结尾双峰收顶**」的教程曲线。整体大部分时间在 **+2~+4 的正向平台**（靠"它真的能做/还会反问/200+报告/老板明天就要"一点点堆获得感），但**每一次进入下一集前，都刻意回落到 -1**（"网上没资料/40个不够/风格词费劲"）——这是**用"现在这一版满足不了我"的小焦虑做低落差**，再被"这不还有第X集"瞬间拉回 +2~+3。真正的**收顶双峰**在 120-125s（"凡条指令几分钟→科技真奇妙"）+4 和 262s（"老板明天就要"）+4、以及**末尾 290-292s（"不再做PPT工人→你是最棒的"）+4**——把"工具好用"在结尾升维成"你被解放了"的**身份共鸣高潮**。**落差来源不是负面张力，而是"预设低期待→证实高惊喜"**：先用"肯定很水吧"把预期压到 -1，再用 demo 证实"不水还很强"，制造"打脸式爽感"。结尾从"方法论(+3)"跳进"情感(+4)"再回落"CTA(+2)"，是典型的"干货给够了→情绪拉一把→收数据"。

**能否复用**：**可，且很通用**。这是「**分级进阶教程 + 周期性"局限-解决"微落差 + 结尾认知/身份升维收顶**」模板，适合一切"方法有多档/可由浅入深"的教学（AI 工具、课程、技能、健身、理财）。**核心可复用动作**：①每级开头用上一级的局限做 -1 微焦虑；②用"这不还有下一级"口语命令拉起；③结尾把"学会了这个技能"升维成"你的人生/身份被改变了"。

### 2. 结尾手法
**总结 → 认知抽象（Agent 帮你干重活，你只给上下文）→ 前瞻判断（今年成为主流的 AI 协作方式）→ 共鸣情感金句（答应我，不再做 PPT 工人，你是最棒的）→ 行动指令（点赞收藏关注）**。
- **为什么这么用**：多重数据目标——①**收藏**：整套"走你公式+4级玩法"怕忘，天然诱藏；②**关注**："这是今年会成为主流的 AI 协作方式"埋"你不想落后就要跟上我"的追更引；③**点赞/评论**："不再做 PPT 工人"用**第二人称直接对观众喊话**，戳中打工人情绪，引发"被戳中了"的点赞与评论共鸣；④**转发**：身份解放金句+"你只需要给足上下文"的认知前瞻，是强传播性"说人话"分享点。落点**从"我会了"升维到"我被解放了"**，让人既学到位又情绪上头。
- **怎么复刻**：教学/工具类结尾套「**一句话总结（做了什么）→ 认知抽象（底层逻辑是什么，如"你只需给上下文"）→ 前瞻判断（"这是未来会主流的方式"拉优越感）→ 第二人称情感金句（"答应我，不再做 XX 工人/你是最棒的"）→ CTA（点赞收藏关注）**」。注意：**情感金句必须在干货给足之后**，且用"你"直接对观众说话，别在结尾又转回说教。

### 4. 情绪元素调用
题材=**AI 工具 / 效率教学（Agent 协作）+ 演示型**。调用情绪：**兴趣/好奇（3分钟20个PPT、分4级）→ 疑惑（"肯定很水吧"）→ 惊喜/被说服（demo 一页页生成、数据新鲜、logo真实）→ 反差爽（原来20分钟→现在几分钟）→ 期待（"这不还有第X集"）→ 小焦虑（"网上没资料/40个不够/风格词费劲"）→ 解决感（反问/200+报告/图片参考）→ 独特性/优越感（私人定制、谁也别找到）→ 场景共鸣（老板明天就要）→ 认知优越（Agent协作将成主流）→ 身份解放/自我肯定（不再做PPT工人，你是最棒的）→ 行动欲（点赞收藏关注）**。核心驱动是「**好奇 → 发现 → 释放**」与「**打工人困境 → 解放承诺**」双线，属"知识干货/教学"题材情绪模型的**高配变体**（好奇→成就/掌控感→行动欲，额外叠加了**反内卷身份共鸣**与**认知优越感**）。

**换题材该调什么**：做成「纯种草/带货」→ 换 痛点焦虑→解决感→冲动（把"你只要给上下文"做成"不买它你就落后"）；做成「情感治愈/反内卷」→ 保留 共鸣→释然→治愈（把"不再做PPT工人"柔化成"别累着/工作不是全部"）；做成「观点/认知颠覆」→ 保留 惊讶→顿悟→优越感（把"让AI反问/Agent协作将成主流"当认知大梗放大的）；做成「故事/人物」→ 换 共情→揪心→感动（把这套方法套给一个"被PPT折磨到凌晨"的具体人，用故事承接）。

### 5. Why + 复用（钩子/开篇/结构/归因）
- **钩子**：为什么——0-15s 定留存，"3分钟/一天20个"用**付出少×回报大**直接戳提效人群；"不是模板/免费/演讲稿配好"先**消灭"AI 很水+怕麻烦+要花钱"三个顾虑**；"小心损失一个亿"用荒诞数字调侃逼收藏。复用——教程/工具类开篇用「**低门槛数字钩（少时间/多产出）+ 否定旧方案 + 扫顾虑 + 夸张收藏句**」四件套。
- **开篇**：为什么——前 25s 把"讲什么(做PPT/给公式)+价值(免费/定制/全自动)+行动(收藏)"一次给足，同时用"这不肯定很水吗"**预设一个质疑**再留反转，让观众带着"看它到底行不行"的好奇往下看。复用——中长教学开篇必"**价值预告 → 疑虑预埋(为反转铺垫) → 行动暗示**"三件套。
- **结构**：为什么——"**分级进阶（1→4 每级补上一级不足）**"用"能覆盖到我这种情况吗"的**递进疑问**替代平铺，让"下一集能补上"成为贯穿期待；"**demo 即论据**"用"眼见为实"替代说理，最省口播却最有说服力。复用——方法/技能类用「分级进阶 + 每级"局限-解决"节拍 + demo 证明」骨架。
- **归因**：为什么——把**最强爆点放结尾做"身份解放"升华**（这是本题最大增量），让"学会了工具"升维成"你不再是 PPT 工人"，既有转发又有情感深度；同时**命名化"走你公式"**+**"让AI反问"**心法 + **"给足上下文即可"**认知，覆盖收藏/评论/关注三种动机；复用——**教学类结尾补一句"认知抽象+身份升华"**，把"我教你一个技巧"变成"我让你看清一个趋势/摆脱一种苦"，比停留在"好用"更有层次也更易传播。

## 备注：发现的新机制（可回填机制库）
- **分级进阶教程骨架（"上一级不够→下一级补"）**：把一套方法拆成多级/多版，每集开头先用**上一级的局限**开一个 -1 新痛点（"网上没资料/40个不够/风格词费劲"），再用"这不还有第X集/小case第X集来了"口语命令转场拉起，形成"能覆盖到我这种情况吗"的递进疑问驱动完播。天然契合 3-10min 分段留存。
- **命名化可复用套路（"走你公式"）**：给万能提示词/指令**取一个带动作感的名字**（走你=出发），使其成为贯穿全片、可传播、可复刻的记忆点；同一公式只需"加一句/换个输入"即可一鱼四吃，制造复利感。
- **反客为主提问式心法**："**为了帮我做好这个，需要我给你提供哪些信息？你来向我提问**"——把"人类给指令"翻转成"AI 反问、人类补上下文"，是 Agent 协作的核心心法；教 AI 工具时的一句"主人翁爽感"爆点。
- **打工人身份解放收尾（"答应我，不再做XX工人 / 你是最棒的"）**：教学方法论后，结尾用**第二人称共情金句**把工具价值从"效率"升维到"身份/尊严"，触发"被理解、被激励"的共鸣转发；与"非效率而梦想"升维类似但更**反内卷/直接喊话**。
- **"预设低期待→证实高惊喜"落差**：开篇先替观众说出疑虑（"这不肯定很水吗"）把预期压到 -1，再用连续 demo 证实"不水还很强"，制造**打脸式爽感**——比直接吹"很好用"更可信、更抓人。
