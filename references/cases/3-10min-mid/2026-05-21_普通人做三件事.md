# 案例 · 普通人就做三件事（155.1s / 805字 / emotion=NEUTRAL）

> 注：原音频落在 155.1s（约2.6min，偏中视频档下沿），源目录为中视频，按**3-10min-mid** 标尺拆解。口播字速偏快（约311字/min），重口头禅填充（呃/啊/嘛/就/对吧），实质信息密度中等，胜在**三点式清单 + 造词记忆点 + 认知反转**。

## 一、文案核心内容
讲"普通人在没有其他机会的前提下，只需做三件事":①**做自媒体**——让更多人看见你（作者自造词「幸运表面积」：接触人越多，幸运值/机会越多）；②**用AI**——AI帮你干活，你只负责思考"什么对别人有价值"，做出来交给前面攒到的流量；③**投资**——拿钱让比你更聪明的人帮你赚钱。
底层逻辑闭环：**曝光(自媒体)→做产品(AI变现)→有钱(投资让聪明人赚钱)**。三个动作互相关联、几乎零成本，是对"普通人没机会"这一信念的**逐点击破**。

## 二、母框架拆解（3-10min 标尺）
- **开篇(0-15s)**：**数字冲击 + 悬念留白 + 价值承诺**三连踩。"普通人就做三件事，就三件事就够了"（数字+断言抓人）+"做什么呢？"（悬念留白吊着）——0-15s 就把"讲什么+有何收益（原来我也有机会）"说清，低认知成本、贴身贴人群。
- **结构**：**观点框架「抛观点→逐条论证(①②③)→互动自曝→回顾收束」**。三个并列论点**各带一个造词/生活化类比**降理解成本，形成"清单式"骨架，观众跟得走。
- **分段留人**：靠**口语命令式转场钩**（"好，第二个是什么呢？""第三个事情是什么呢？"）把中段拽住；每个论点块**内部先给结论再补解释**，块内自洽、不绕。
- **语言/人设**：**大哥/朋友式口播**，极口语、多口头禅（呃/啊/嘛/对吧/对不对），真实感强、说教味被口语化冲淡；用"胡子"自称（朋友提问"为什么自己不创业"）立**落地的亲历者人设**；"哥们""老老实实上班/卖时间卖体力"带点糙、带点敲打。
- **价值**：主=**认知**（打破"普通人没机会、只能上班卖时间"的信念，给出可执行的"翻身三步"）；副=**实用**（自媒体/AI/投资三个可落地动作）。1主+1副，聚集不散。
- **记忆点**：**造词「幸运表面积」** + **具象类比「你能帮我挣100，我愿意给你10块，20也无所谓」** + **金句「不会可以学」** + **反转句「我没那么聪明，我只干一件事，我专修判断力，把钱投给聪明人让他帮我赚钱」**。
- **结尾**：**三件事回顾收束 + 行动指令**（"有钱的投资，让更聪明的人帮你赚钱"），首尾呼应、闭环完整。
- **字速**：805字 / 155.1s ≈ 311字/min（含大量口头禅；扣掉填充词后实质密度中等）。是**观点口播偏快**档。

## 三、爆款归因提炼（可复刻公式）
1. **开篇公式 = 数字断言 + 悬念设问 + 人群贴脸**："就三件事就够了"先给确定性+数字（做多少），"做什么呢？"再造悬念。比对"我教你一个搞钱方法"更有记忆钩。
2. **结构公式 = 三点清单 + 每点造一个词/类比**：把"改变命运"这种大命题拆成 **3 个可记住的动作**（自媒体/AI/投资），每个动作配一个"人话名字/生活化换算"，降低理解成本、提高复述率（幸运表面积、挣100给10块、专修判断力）。
3. **留人手法 = 段间口语命令转场**：用"好，第二个是什么呢/第三个事情是什么呢"把观众自然带进下一段，防中段跳走；三件套结构本身自带进度条感（"这才第2件，还有1件"），天然留人。
4. **价值策略 = 信念击破**：先立"普通人真的没别的机会（现实焦虑）"，再用三条低成本路径**逐一反驳**，把"只能上班"的无力感翻转为"你也可以做"，完成情绪托举（这是认知/励志类高传播核心）。
5. **人设策略 = 亲历者 + 自曝式幽默**："我创过三次业…我没那么聪明…专修判断力"，用**承认不完美 + 分享真实选择**立可信度，比"我教你发财"更打动人也更合规。

## 四、金句与可使用场景
- **金句①**：「普通人就做三件事，就做三件事就够了。」
  - 场景：普通人身处困境/焦虑/想改变的话题开局。
  - 用途：开头钩子/封面字（数字+断言最要点题）。
  - 适用时长：全档（短视频可精简成"普通人就做三件事"）。
  - 用法提示：接一句"做什么呢"吊悬念；数字越小越有冲击，"三件事"比"五步法"更易记。
- **金句②**：「你能帮我挣100，我愿意给你10块，给你20也无所谓。」
  - 场景：表达"价值交换/为价值付费"、"我为什么付费"的论证。
  - 用途：中段记忆点 / 评论互动（"你愿意为有用付多少？"）。
  - 适用时长：中视频、短视频。
  - 用法提示：用**具体小数字 + 让步（也无所谓）**把抽象"价值"一次说透，比讲"付出才有回报"有画面。
- **金句③**：「我不需要在聪明上跟别人比，我只干一件事，我专修判断力——把钱投给聪明人，让他帮我赚钱。」
  - 场景：反内卷/不卷智力/投资理财/心态、承认自己不擅长的事。
  - 用途：中段认知反转暴点 / 结尾升华 / 封面字。
  - 适用时长：中视频、长视频。
  - 用法提示：先自曝短板（"我没那么聪明"）再抛"我专修判断力"的反转，形成"谦逊→清醒"落差；最后落到"让别人帮我赚钱"完成爽点。
- **金句④**：「不会可以学；如果你连学都不想学，那就老老实实上班、卖时间卖体力。」
  - 场景：劝人行动/破除拖延与"我不会"借口。
  - 用途：中段敲打/记忆点 / 评论引导（"你是哪种？"）。
  - 适用时长：全档。
  - 用法提示：**"不会可以学"** 是锚，后半句用**直白对照**（卖时间卖体力）做一记敲打，形成张力但不辱骂。

### 2. 结尾手法
**三件事回顾 + 行动指令收束**（"有钱的投资，让更聪明的人帮你赚钱"）。
- **为什么用**：首尾呼应的**总复习式收口**，把三件事再点一遍（强化记忆、便于截图复述）；落点放在"让更聪明的人帮你赚钱"，**把"行动"变成"滚起来的财富逻辑"**，给人"我也能这样"的期待，服务的是**收藏（怕忘）+ 转发（想安利给同样迷茫的朋友）+ 评论（认同"说得对"）**。
- **怎么复刻**：结尾用"所以三个事儿啊：第一…第二…第三…"把开头承诺**逐条兑现**（闭环），最后落到一句**最"聪明/轻松"的结论**做情绪最高点，别停在"你还得努力"这种重话上。

### 5. Why + 复用（钩子/开篇/结构/归因）
- **钩子**：为什么用"数字断言+设问"——**3秒内给确定性+吊好奇**，直接锁"像我一样的普通人"；复用——**"就做X件事就够了"+"哪X件？"** 是万能句式，任何给方法/出路的选题都能套。

- **结构**：为什么用"三点清单+每点一个造词/类比"——**清单给进度感、造词给记忆锚**，观众记得住、愿意转发；复用——**把大命题拆成3个可执行动作**，每个动作配一个人话名字或生活化换算。
- **归因**：为什么"信念击破+敲打托举"有效——先承认"普通人真的难"拉近距离，再给出口放大希望，**这是励志/认知类最高传播的心理机制**；复用——**先共情困境(不是PUA) → 单点击破("你不会可以学/你没成本去试") → 给反转出口(让别人帮你赚钱)**。

## 七、可复刻要点
1. 给方法的选题，开头用"数字断言+设问"（就X件事就够了→哪X件），1句话锁人群。
2. 大命题拆成 **3 个可执行动作**，每个动作配一个**造词**或**生活化类比**当记忆点（幸运表面积 / 挣100给10块 / 专修判断力）。
3. 中段插一句**扎心敲打**（连学都不想学就上班卖时间）做情绪落差，再给出口，落差不靠吼靠"扎心+解药"。
4. 结尾**先复述三件事闭环**，再落到一句**最轻最聪明**的结论（让更聪明的人帮你赚钱）做情绪高点。
5. 人设用**亲历者自曝**（我创过三次业/我没那么聪明），比"我教你发财"更可信、更合规。
