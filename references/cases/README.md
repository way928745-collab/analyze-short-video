# 案例库说明（schema 与目录结构）

本目录是 `analyze-short-video` 的**自我强化库**。每遇一条优秀爆款，按统一 schema 归档，发现的**新公式/新手法**回填到 `SKILL.md` 第 3 部分公式库。案例越多，创作越准。

## 目录结构

```
references/cases/
├── README.md              # 本文件：schema + 说明
├── 15s-3min/              # 15秒–3分钟 短视频档案例
│   └── example_60s_zhishiganhuo.md
├── 3-10min-mid/           # 3–10分钟 中长视频档案例
│   └── _index.md
└── 10min-plus/            # >10分钟 长视频档案例
    └── _index.md
```

## 案例归档统一 schema

每个案例一个 `.md`，文件头为 YAML 元信息，正文按母框架拆解，末尾是归因提炼与可复刻要点。

```yaml
---
title: <案例名>                # 一眼能认出的标题
duration_tier: 15s-3min      # 三选一：15s-3min / 3-10min-mid / 10min-plus
platform: 抖音                 # 抖音/视频号/B站/小红书/快手
track: 知识科普                # 知识科普/人物故事/深度观点/经验复盘/测评解析/情感叙事/剧情
content_form: 口播             # 口播/画面解说/混剪/PPT/实拍
core_goal: 涨粉               # 涨粉/人设/带货/引流/品牌/知识变现
core_value: 认知                # 实用/情绪/认知/娱乐
target_audience: 职场人        # 目标人群一句话
date_added: 2026-08-27        # 入库日期
source_url: ""                # 视频/文案来源链接（可选）
---
```

正文建议小节：
1. **文案原文或结构转录**（能贴原文贴原文，不能贴就逐段概括结构）
2. **母框架拆解**：按 `SKILL.md` 第 2 部分维度展开，**用对应时长档的侧重表当标尺**；不必 19 个维度面面俱到，挑对本案例最关键、最能说明"为什么爆"的维度深挖。
3. **爆款归因提炼**：提炼为可复刻公式——钩子类型及为何有效、结构框架及为何留人、情绪曲线、价值主副、记忆点、金句。
4. **金句与可使用场景**（必填）：抽出 1–3 条金句/高光句，每条标注"可使用场景 + 用途位置 + 适用时长 + 用法提示"，并**同步追加到 `references/quotes/gold_quotes.md`**。
5. **可复刻要点**：下次我能照着做（具体到可直接套用的 1–3 条）。
6. **（可选）跨时长迁移**：这条思路压缩成短版 / 展开成长的取舍。

## 去重与强化规则
- **去重**：同一视频不重复归档；同一手法多次出现时，累计到公式库而不是堆案例。
- **强化**：发现 SKILL.md 公式库没有的持久手法 → 回填公式库；发现全新的内容形态/时长打法 → 考虑在 SKILL.md 增加一个维度或迁移案例。
- **诚实标注**：案例若为示意或凭记忆概括，须在开头注明"示例/示意，非逐字原文"；引用真实数据需保留出处。
