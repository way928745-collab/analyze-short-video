# 案例 · 好了好了这下坏了（40.6s / 236字 / emotion=HAPPY）

## 一、文案核心内容
把 **AI 拟人成"打工人"**，通篇以 AI 的第一人称口吻，一条条列举"AI 上岗后打工人才敢想却做不到的理想条款"：①不给钱不干活，少一分钱或一秒钟都不干；②干活前需求必须说清楚，否则我就反复改；③每改一次都要收费——我才不是那种"随你改多少次"的窝囊废打工人；④最狠一条：**改出问题了不归我管，是你的需求/你领导的问题，我不背这个锅**。结尾一句反讽收顶：**"坏了坏了，这下好了，让 AI 享受上了啊？"** 讽刺的是——现实打工人被无限改稿、被背锅、被压榨，而这些"privilege"如今全成了 AI 的"标配"。

## 二、母框架拆解（15s-3min 标尺）
- **开篇(0~4s)**：**身份反差钩子**——"AI 过上了打工人梦想的生活"一句话立人设+设反差，制造"AI 凭啥享受？"的停留欲。校验三要素：相关性高(打工人+AI 双热点)、零门槛、剥夺感="那 AI 到底能多爽？"。
- **结构**：**条款清单框架**「立身份→逐条列"特权"①②③④→关键一条前提提示→金句收顶」。是 情绪+娱乐 混合，非常轻的"伪逻辑"。
- **语言/人设**：AI 拟人第一人称，**梗化口语+俏皮尾缀**(哟/哦/啊/对不对)——像 AI 在认真讨价还价，越一本正经越好笑；"窝囊废打工人""不背这个锅""坏了坏了"都是高传播口语梗。
- **核心价值**：主=**情绪**(共情打工人+爽感/痛快) + 副=**娱乐**(黑色幽默反讽) + 一点**认知**(AI 替代的荒诞感)。
- **记忆点金句**："**我是不背这个锅的啊**"(最高记忆点，甩锅梗) + "**不是窝囊废打工人**"(身份反差梗)。都在中后段，截图/转述属性极强。
- **结尾(36.9~40.6s)**：**反讽收顶**——"坏了坏了，让 AI 享受上了啊？"用自嘲式反问收，不煽情、不喊口号，靠"咂摸回味"完成落下。

## 三、爆款归因提炼（可复刻公式）
1. **钩子公式 = 身份反差 × 结果前置**："X 过上了 Y 的生活"——把稀缺/理想(打工人梦想)甩给一个非人客体(AI)，瞬间勾起"凭什么？到底多爽？"。
2. **结构公式 = 拟人化条款清单**：用"①②③④一条条列规则"的**伪说明书**格式，把槽点堆出来；括号式"每改一次收一次费"让荒诞感滚雪球。
3. **留人手法 = 每 6~8s 抛一条新"特权"** + 关键一条前放"最重要最重要的一点来了"(悬念前置)，憋住口气拉到峰值(不背锅)。
4. **价值组合 = 共情(打工人憋屈) + 爽感(替打工人"占了便宜") + 黑色幽默(AI 拟人)**：这组合极易点赞+收藏+转发(转发给同事/朋友"这才是理想工作")。
5. **人设 = 嘴替/梗王**："#嘴替上线"tag 点明定位——替打工人把不敢说的话以荒诞方式说出口。

## 六、机制层深度分析

### 1. 逐段情绪曲线（-5~+5，句子级，不跳段）
- `0.2s` 开篇身份反差钩子(AI过上了打工人梦想生活) → **+1**
- `4.0s` 第一条：不给钱不干活(少一分一秒都不干) → **+2**
- `11.6s` 第二条：需求必须说清楚否则反复改 → **+2**
- `17.2s` 第三条：每改一次收一次费(收你钱的→+3)；"不是窝囊废打工人"对比 → **+3**
- `26.4s` 关键前置："最重要最重要的一点来了"(悬念顿一顿) → **+2**
- `33.9s` 第四条：改出问题不关我事/你领导的问题/我是不背这个锅的 → **+4**（喜剧峰值/爽）
- `37.5s` 结尾反讽：坏了坏了，让AI享受上了啊 → **+3**

**曲线**：`+1@0.2s → +2@4.0s → +2@11.6s → +3@17.2s → +2@26.4s → +4@33.9s → +3@37.5s`
（峰值在 +4@33.9s 的"不背锅"，尾段回落 +3 做喜剧落点。）

**为什么这么排**：开头 +1 轻钩子先让你"咦，有意思"；中段 0~+3 逐条加码、温和爬升（+2→+2→+3），**故意不急着给高潮，靠"一条比一条离谱"的滚雪球**维持好奇；到 26.4s"最重要的一点来了"**故意往回顿一拍(+2)**制造悬停；33.9s 甩出"不背锅"砸到 +4，**落差即爽感**；结尾不再拔高，回落 +3 自嘲收尾——**"慢热滚雪球→一句话引爆→自嘲落地"**。这条曲线模板**非常适合"槽点清单/吐槽加码"类文案**（职场、租房、甲方吐槽等），可整体套用。

### 2. 结尾手法
用了 **"反讽金句 + 自嘲式反问"** 收尾（"坏了坏了，这下好了，让AI享受上了啊？"）。
- **为什么这么用**：目标数据是**转发+评论**。结尾不引导"点赞关注"，而是用"让AI享受上了"一句把全篇的黑色幽默封顶，留给观众"会心一笑后想转给同事吐槽"的冲动；"坏了坏了"口语戏谑感拉满评论区的"哈哈哈哈/太真实了"。
- **怎么复刻**：全场**装正经**（一本正经列条款），结尾一句"可是/坏了坏了"式**破功自嘲**，用口语语气助词(啊/嘛/哟)收，不喊口号。

### 3. 节奏与爆点（秒位全标注）
**爆点**：`0.2s`身份反差钩子 ｜ `17.2s`"不是窝囊废打工人"(身份反差) ｜ `26.4s`"最重要的一点来了"(悬念前置) ｜ `33.9s`"我是不背这个锅的"(主爆点/甩锅梗) ｜ `37.5s`"让AI享受上了"(反讽收顶)。
- **间隔**：约 **6~9s 一个爆点**（比情绪类更密，属"槽点密集"型节奏）。
- **信息密度**：236字 / 40.6s ≈ **349字/分钟**（偏快，适合梗化口播+高密槽点；无画面依赖时语速需稳）。
- **爆点排法**：**前置提示+紧挨高光**——"最重要的一点来了"这句专门用来给 33.9s 主爆点热身；**首尾双爆**（0.2s 钩子 + 37.5s 收顶）锁住完整观看。
- **新文案同类主题怎么设**：设一个"X 的梦想条款"清单→开头立反差身份 → 每 6~9s 一条新"特权"(逐条加码) → 放一条"最狠的是…"作悬念前置 → 一句话引爆主梗 → 自嘲收顶。天然适配"职场/生活吐槽"系列。

### 4. 情绪元素调用
题材=**职场吐槽/AI替梗/黑色幽默嘴替**。调用情绪序列：**好奇(咦AI这么爽？)→会心一笑(确实)→共鸣(打工人狠狠共情)→痛快/爽(AI替你占了便宜)→感叹→反讽自嘲(坏了坏了)**。核心是**"替观众出一口气"的痛快感**，而非悲伤焦虑。
**换题材该调什么**：改成「**干货教学**」→ 换 好奇→新奇→清晰→成就感(撑住干货节奏)；改成「**反大佬/讲故事**」→ 换 好奇→悬念→惊讶→释然；改成「**情绪疗愈**」→ 换 好奇→共鸣→被理解→治愈。

### 5. Why + 复用（钩子/开篇/结构/归因）
- **钩子**：为什么——用"AI 享受了 Y 的生活"制造**客体反差**，比直接说"打工人好惨"更抓眼、不卖惨；复用——凡"XX 梦寐以求/已经过上了"类话题，套"**某非人客体 过上了 Y**"。
- **开篇**：为什么——首屏一句话立"拟人嘴替"人设+反差，给足停留理由；复用——**第一句就把"谁在替谁说话/谁享福了"交代清楚**。
- **结构**：为什么——**条款清单**让槽点"可计数、可堆叠"，越列越离谱就越好笑；复用——吐槽/反讽类文案优先用"①②③逐条列"组织，别平铺直叙。
- **归因**：为什么——"**共情+爽感+幽默**"三合一在打工人群体里传播极强，且"AI 替代"话题自带流量；复用——做职场/生活吐槽，先找到一个**所有人都憋着的槽点**，再让一个新角色替你说出来（拟人/嘴替），比本人抱怨更易爆。
